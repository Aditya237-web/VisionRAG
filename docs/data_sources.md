## Making the Scanned PDF (BERT_paper01.pdf)

The `BERT_paper01.pdf` is a synthetic scanned PDF created by rasterizing the original BERT paper PDF at 130 DPI and saving as a PDF with no text layer.

The script `scripts/make_scan.py` expects the original BERT paper PDF (downloaded from https://arxiv.org/pdf/1810.04805) as input and writes `BERT_paper01.pdf` to the current working directory (or the `data/pdfs/` directory when run from the repo root).

```bash
# Requires: Python 3.13+, PyMuPDF (pymupdf)
python -c "
import fitz
doc = fitz.open('https://arxiv.org/pdf/1810.04805')  # BERT paper
# Rasterize each page at 130 DPI
pdf_bytes = doc.convert_to_pdf(dpi=130)
with open('BERT_paper01.pdf', 'wb') as f:
    f.write(pdf_bytes)
print(f'Created BERT_paper01.pdf with {doc.page_count} pages')
"
```

Or use the provided script:

```python
# scripts/make_scan.py
import fitz
import sys

def make_scan(input_url_or_path: str, output_path: str, dpi: int = 130):
    """Rasterize a PDF to create a scanned version with no text layer."""
    doc = fitz.open(input_url_or_path)
    pdf_bytes = doc.convert_to_pdf(dpi=dpi)
    with open(output_path, "wb") as f:
        f.write(pdf_bytes)
    print(f"Created {output_path} with {doc.page_count} pages at {dpi} DPI")

if __name__ == "__main__":
    # BERT paper from arXiv
    make_scan("https://arxiv.org/pdf/1810.04805", "BERT_paper01.pdf", dpi=130)
```

Run with:
```bash
python scripts/make_scan.py
```

Note: The original PDFs (paper1.pdf, paper2.pdf, f_paper01.pdf, f_paper02.pdf) should be downloaded from the links above and placed in `data/pdfs/`. `BERT_paper01.pdf` is generated by `scripts/make_scan.py`.
